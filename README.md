# Hi, I'm Tiago

I'm a WordPress developer. 10+ years of it: busy sites, multi-site setups, headless migrations and online stores. That's where I learned that people depend on what you ship.

In my own time I build AI agents, and I'm a bit obsessive about making them plan and check their work before anything ships. Agents are fast. The bugs show up later, in review. I'd rather find them before that. It's the part of the work I enjoy most right now, and where I want to spend more of my time.

## Things I made

- **[ForgeBee](https://github.com/forbee-dev/ForgeBee)**: my open-source framework for AI coding agents. For the big decisions, one agent argues for the plan, another argues against it without seeing the first, and a judge decides. It sounds silly. It works. Runs in Claude Code, Codex, Cursor and Gemini from one source.
- **[Buddy](https://github.com/forbee-dev/buddy)**: a tiny pixel mascot on your macOS desktop for every Claude Code session. `brew install --cask forbee-dev/tap/buddy`
- **[wordpress-local-dev](https://github.com/forbee-dev/wordpress-local-dev)**: a web UI that spins up local WordPress sites in Docker, so I stop doing it by hand.
- **WP Render Blocks**: a side project that serves React components from AI design tools as server-rendered blocks inside WordPress, so search engines can actually read them.
